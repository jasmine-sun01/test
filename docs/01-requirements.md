# 学校物品二维码管理系统 — 需求文档

## 1. 项目概述

为学校设计一套基于二维码的物品全生命周期管理系统，覆盖物品从**录入→借出→归还→报废**的完整流程。每件物品生成唯一二维码，扫码即可查看信息、办理借还手续。

前后端均使用 Python 开发：后端提供 REST API，前端提供 Web UI。

---

## 2. 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| **管理员 (Admin)** | 学校资产管理人员 | 全部权限：录入、编辑、删除物品、审批报废、管理用户、查看报表 |
| **教职工 (Staff)** | 老师/教务人员 | 借出、归还、申请报废、查看自己的借用记录 |
| **学生 (Student)** | 在校学生 | 借出、归还、查看自己的借用记录 |

---

## 3. 功能需求

### 3.1 物品录入

- 管理员可录入物品信息：名称、分类、型号、购入日期、购入价格、存放位置、备注
- 物品分类支持自定义，如：电子设备、体育器材、实验器材、办公用品、图书等
- 录入后系统自动生成**唯一编号**和对应的**二维码图片**
- 支持批量录入（CSV 导入）
- 二维码可打印（支持导出 PDF，含物品名称+编号+二维码）

### 3.2 物品查询

- 扫描二维码直接跳转物品详情页
- 支持按名称、分类、编号、状态等条件搜索
- 物品详情展示：基本信息 + 当前状态 + 借用历史

### 3.3 借出管理

- 教职工/学生扫码或搜索物品，发起借用申请
- 填写：预计归还日期、借用用途
- 物品状态变为「已借出」，记录借用人、借出时间
- 同一物品在借出状态下不可重复借出
- 支持查看所有在借物品列表

### 3.4 归还管理

- 借用人扫码或在「我的借用」中操作归还
- 管理员确认归还，检查物品状况
- 物品状态变回「可用」
- 记录实际归还日期
- 逾期未还的物品自动标记提醒

### 3.5 报废管理

- 教职工/管理员可对物品发起报废申请，填写报废原因
- 管理员审批报废申请
- 审批通过后物品状态变为「已报废」，不可再借出
- 报废记录永久保留，可追溯

### 3.6 仪表盘与报表

- 首页仪表盘展示：物品总数、在借数量、逾期数量、已报废数量
- 借用频次统计（哪些物品最常借）
- 逾期排行
- 可按时间段导出借用报表（CSV）

### 3.7 用户管理

- 管理员可添加/禁用用户
- 用户登录认证（用户名+密码）
- 角色分配

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| **部署** | 单机部署，支持 Docker 一键启动 |
| **数据库** | SQLite（轻量，适合学校场景，无需额外数据库服务） |
| **并发** | 支持 50+ 同时在线用户 |
| **响应式** | 前端适配 PC 和手机浏览器（扫码场景多为手机） |
| **二维码** | 标准 QR Code，扫码后打开物品详情 URL |
| **安全** | 密码哈希存储，Session 登录认证（用户名+密码） |

## 5. 物品生命周期状态机

```
         录入
          │
          ▼
       ┌──────┐
       │ 可用  │◄─────────┐
       └──┬───┘          │
          │ 借出          │ 归还
          ▼              │
       ┌──────┐          │
       │ 已借出 │─────────┘
       └──┬───┘
          │
          │ 报废申请（可用/已借出 均可发起）
          ▼
       ┌──────┐
       │ 待报废 │ ←── 管理员审批中
       └──┬───┘
          │ 审批通过
          ▼
       ┌──────┐
       │ 已报废 │ ←── 终态，不可逆
       └──────┘
```

|------|------|

| 仪表盘 | 统计概览 |

| 物品详情 | 扫码跳转，展示信息+状态+历史 |
| 物品录入 | 表单录入新物品 |
| 借用管理 | 在借列表、借出操作、归还操作 |
| 报废管理 | 报废申请列表、审批操作 |
| 用户管理 | 管理员管理用户账号 |
| 我的借用 | 个人借用记录 |
| 二维码打印 | 批量选择物品，生成可打印的二维码 PDF |
